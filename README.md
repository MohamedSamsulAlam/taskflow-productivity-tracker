# TaskFlow — Smart Task Manager

A responsive productivity tracker built with HTML, CSS, and vanilla JavaScript.

## Features
- Create, read, update, and delete tasks (CRUD)
- Work, Personal, and Study categories
- Due dates
- Active and Completed filters
- Search tasks by title or category
- Browser `localStorage` persistence
- Responsive layout and task-completion animation

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser, or use VS Code with Live Server.
3. Add tasks and refresh the page to verify local storage persistence.

## Tech stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Browser localStorage API

## Notes
This is a frontend-only demo. Tasks are saved in the current browser on the current device; they are not synced to an account or server.
